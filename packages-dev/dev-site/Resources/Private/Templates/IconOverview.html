Every icon the academic extensions register, as the registry lists it at render time - see IconOverviewProcessor. Each identifier is rendered three times with the markup a frontend template of the extensions uses: at 1em inside a line of text, at 2rem, and in the text colour of a dark ground, so an icon that is not drawn in currentColor stands out in the third column. Style attributes only: the frontend Content Security Policy of both cores allows them and blocks an inline style element without a nonce.
