The responsive image of the academic extensions. The arguments and the four presets are public API, documented in the "Templates" chapter of academic_base: - image An Extbase or a core file reference. Empty renders the placeholder. - preset "card", "detail", "logo" or "teaser" - one "Preset-" section below each. - cropVariant Applied to every source and to the fallback image. Default: "default", which the core image view helpers apply to an empty value. - placeholder An "EXT:" path, rendered when there is no image. Empty renders nothing. - alt The alternative text. Default: the alternative text of the file. - class The class of the image element. - showCaption Renders the description of the file as a caption. - showCopyright Renders the copyright of the file, a field of EXT:filemetadata. A project changes the breakpoints and widths of every academic plugin at once by overriding this one file through the partial root path of each plugin. An Extbase file reference wraps the core one, which carries the metadata. Array access, because getProperty() throws for a field that does not exist. A vector image needs neither processing nor sources.
