The message of one validation error of a field. A label for the field and the error code wins, for example "create.job.contactEmail.error.1221559976", then a label for the error code alone, "create.error.1221559976", then the message of the validator. All three are given the arguments of the error, so a label can name the value or the limit a validator reports with "%s". Arguments: error The error, "TYPO3\CMS\Extbase\Error\Error". elementId The id of the field, ".". extensionName The extension of the labels. {f:translate( key: 'create.{elementId}.error.{error.code}', default: message, arguments: error.arguments, extensionName: extensionName )}
