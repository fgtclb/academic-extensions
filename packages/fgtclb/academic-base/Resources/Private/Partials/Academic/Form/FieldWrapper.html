The label, the required mark, the validation state and the help text around one field of a frontend form. The field partials next to it render it with the field as "elementContent", or render the partial named in their "fieldWrapperPartial" argument instead, which receives the same arguments. Arguments: element The field: "identifier", "validations" and an optional "help". elementId The id of the field, ".". class The class of the wrapping element. elementContent The rendered field. extensionName The extension whose label "create..label" is shown, and whose labels "create.required" and the error messages of "Academic/Form/ErrorMessage" are read. The field partials mark a field that failed validation with "invalid" and point "aria-describedby" to the element "-error", "ace-field-errors", which holds its messages, each in an "ace-field-error". It follows the field as its sibling.
