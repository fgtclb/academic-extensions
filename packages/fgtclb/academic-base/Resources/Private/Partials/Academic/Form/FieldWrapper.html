The label, the required mark, the validation state and the help text around one field of a frontend form. The field partials next to it render it with the field as "elementContent", or render the partial named in their "fieldWrapperPartial" argument instead, which receives the same arguments. Arguments: element The field: "identifier", "validations" and an optional "help". elementId The id of the field, ".". class The class of the wrapping element. elementContent The rendered field. extensionName The extension whose label "create..label" is shown.
