One module of a semester. Arguments: - module: the module record. - semester: the semester it belongs to, for the label the dialog trigger announces to a screen reader. The label names the note and the credit points of the semester only when it has them. A module with neither a description nor an audio file has nothing to show, so it carries no trigger and no dialog. An override may move `data-study-plan-dialog-trigger` onto this element itself; the script pairs the trigger with the dialog of the same module either way.
