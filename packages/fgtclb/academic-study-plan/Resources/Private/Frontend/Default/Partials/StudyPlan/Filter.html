The category filter of the study plan. Arguments: - collapsible: renders the marker that makes the script put the list behind a toggle button. Off unless the site switches it on. The list holds exactly one item and that item is a template rather than a control: the script empties the list and clones the item once per category the rendered modules carry. It is `hidden` so that its placeholder text never reaches the screen on a page whose script did not run, and the script takes the attribute off every clone it builds.
