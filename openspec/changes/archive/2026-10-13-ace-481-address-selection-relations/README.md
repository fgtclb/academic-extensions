# ace-481-address-selection-relations

The address selects of a page contact become relations to the address records of its contract, so a copied contract or profile selects its own addresses, a translation keeps the default language addresses, and the reference index knows every selection, on TYPO3 v12 and v13. Backport of the copy and reference index part of `ace-481-address-selection-live-records` on `main`.
